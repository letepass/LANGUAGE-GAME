# Language Game – Interactive English Learning

Language Game is an educational project designed to help users improve their English pronunciation, vocabulary, and speaking skills through interactive gameplay. The main goal of this project is to make language learning more enjoyable, accessible, and effective by combining technology with fun learning activities.

## Project Overview

The game allows users to practice speaking English and develop their vocabulary through different challenges. Using speech recognition technology, the program records the user's voice and converts spoken words into text. This helps users practice pronunciation and become more confident when speaking English.

The project also includes a translation feature that allows users to translate recognized speech into a language of their choice. This feature helps learners understand unfamiliar words and phrases while supporting multilingual learning.

## Key Features

- **Speech Recognition:** Converts spoken language into text using speech recognition technology.
- **Pronunciation Practice:** Encourages users to practice English words and improve their speaking confidence.
- **Vocabulary Development:** Helps learners expand their English vocabulary through interactive exercises.
